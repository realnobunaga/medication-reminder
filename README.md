# 药小助 — AI 智能用药提醒助手

> 用 AI 解决每天浪费 10 分钟的用药管理问题

## 功能

- **AI 解析处方** — 粘贴处方文字，自动提取药名、剂量、频次、时间
- **每日用药时间表** — 时间轴展示，逐项打勾标记已服用
- **用药问答** — 药物冲突、副作用、漏服补救等即时回答

## 使用

直接打开 `index.html` 即可使用（零依赖、纯前端）。

无需 API Key 也能完整体验 Demo 模式。配置 API Key（DeepSeek / OpenAI 等）后可获得更精准的 AI 解析和问答。

## 截图

打开页面 → 点击「填入示例处方」→ 点击「AI 智能解析」→ 切换到「今日用药」查看时间表。
